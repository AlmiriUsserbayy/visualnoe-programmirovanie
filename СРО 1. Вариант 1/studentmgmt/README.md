# Student Management System (JavaFX)

Мини-проект по дисциплине «Визуальное программирование». Вариант №1.
Выполнил: Студент 3-го курса ОП «Информационные системы».

## Использованные технологии
* **Язык**: Java 17 / 21
* **Технологии GUI**: JavaFX, FXML, Scene Builder
* **Сборщик проекта**: Maven

## Соответствие техническим требованиям
1. Разметка вынесена в FXML, логика обрабатывается в Controller-классах.
2. Использовано 3 контейнера (BorderPane, VBox, HBox, GridPane) и более 5 элементов управления (Button, TableView, ComboBox, TextField, Label, MenuBar).
3. Встроено 10 демонстрационных записей в таблицу TableView.
4. Полностью реализованы добавление, редактирование, удаление, живой поиск по ФИО и фильтрация студентов по академическим группам.
5. Присутствуют MenuBar, ToolBar, Строка состояния (Status Bar) и горячие клавиши (`Ctrl+Q` для выхода).
6. Реализовано 2 окна: Главное окно со списком и диалоговое окно формы добавления/редактирования с модальным режимом.
7. Реализована строгая валидация числовых диапазонов GPA (0.0–4.0) и текстовых полей с защитой от сбоев (NumberFormatException).

## Инструкция по запуску
Для сборки и запуска приложения выполните в терминале команду:
```bash
mvn javafx:run
```
