1. Что такое JavaFX?
Это библиотека Java для создания кроссплатформенных графических приложений с насыщенным пользовательским интерфейсом.

2. Для чего используются Stage и Scene?
Stage (сцена) представляет собой главное окно приложения (оболочку), а Scene (сцена) — это контейнер для всего содержимого (кнопок, текста) внутри этого окна.

3. Что такое Scene Graph?
Это древовидная структура данных, в которой хранятся все элементы интерфейса (узлы/nodes) приложения.

4. Для чего нужен Scene Builder? 
Это визуальный редактор, позволяющий перетаскиванием мыши (Drag-and-Drop) быстро собирать дизайн интерфейса без написания кода.

5. Что такое FXML?
Это язык разметки на базе XML, который используется для описания внешнего вида и структуры пользовательского интерфейса отдельно от логики.

6. Для чего используется fx:id?
Это уникальный идентификатор элемента в файле FXML, по которому Java-код может находить этот элемент и управлять им.

7. Какую роль выполняет @FXML? 
Эта аннотация связывает переменные и методы из Java-контроллера с компонентами и событиями, описанными внутри FXML-файла.

8. Что такое Controller?
Это Java-класс, содержащий логику управления интерфейсом: он обрабатывает нажатия кнопок, обновляет текст и управляет поведением программы.

9. Чем VBox отличается от HBox?
VBox выстраивает дочерние элементы вертикально (в один столбец), а HBox — горизонтально (в одну строку).

10. Для чего применяется GridPane?
Этот контейнер позволяет располагать элементы интерфейса в виде гибкой таблицы (сетки) из строк и колонок.

11. Как получить текст из TextField?
С помощью вызова метода .getText() у объекта соответствующего текстового поля.

12. Для чего используется Alert?
Для вывода всплывающих диалоговых окон с сообщениями об ошибках, предупреждениями или информацией для пользователя.

13. Что вызывает NumberFormatException?
Попытка преобразовать строку, содержащую буквы или недопустимые символы, в числовой тип данных (например, через Integer.parseInt()).

14. Для чего используется initialize()?
Этот метод автоматически вызывается после загрузки FXML-файла и служит для начальной настройки элементов (например, заполнения списков данными).

15. Почему необходимо проверять ввод?
Чтобы приложение не падало из-за ошибок, не обрабатывало некорректные данные (например, отрицательный возраст) и вело себя предсказуемо для пользователя.
